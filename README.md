## 🌟 Core Feature Highlights

- **💧 1-Click Water Reordering**: Instant reorder workflow for 20L water cans, PET bottle packs, and dispensers.
- **📅 Flexible Subscriptions**: Recurring delivery scheduling (Daily, Alternate Days, Weekly, Monthly) with one-tap pause & modify.
- **🚚 Live Order & Driver Tracking**: Real-time order status timeline with delivery partner details, vehicle number, and ETA map view.
- **📍 Address & Wallet Management**: Saved delivery locations, wallet balance, UPI / Credit Card / COD payment modes, and coupon discounts.
- **💬 AquaBot 24/7 AI Assistant**: Interactive customer support chatbot for TDS, pH water quality queries, and delivery assistance.
- **📱 Desktop & Mobile Responsive Showcase**: Split desktop presentation layout featuring live scannable QR Code & smartphone mockup.

## 💻 Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Library**: React 19
- **Styling**: Tailwind CSS v4
- **Animations**: Motion (Framer Motion)
- **Icons**: Lucide React
- **Type Checking**: TypeScript

## 🛠️ Local Setup & Development

### 1. Prerequisites
Ensure you have Node.js v18.0.0 or higher installed.

### 2. Installation
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production
```bash
npm run build
npm start
```

## 📦 Deploying to GitHub & Vercel

1. **Push to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - AquaDrop client prototype ready for Vercel"
   git branch -M main
   git remote add origin https://github.com/your-username/aquadrop-app.git
   git push -u origin main
   ```

2. **Deploy on Vercel**:
   - Import your GitHub repository on [Vercel Dashboard](https://vercel.com/new).
   - Vercel automatically detects Next.js framework settings.
   - Click **Deploy**!
